# Initial retrospective

Skills supply context-sensitive design/operation guidance. The Assay turns a finite subset into typed snapshot predicates plus retained executed-command evidence. Broader best practices remain a sourced decision guide rather than an opaque compliance score.

Reddit, Medium, Substack and specialist sources contributed failure scenarios. Overbroad claims and workload-specific tuning numbers were rejected as universal rules. Pinned primary documentation and real native tests provide the product-semantic basis.

The native fixtures demonstrate both valid and rejected behavior. A successful test of an intentionally insecure fixture does not make that fixture production compliant. Package isolation, input freshness, incomplete scope and output boundaries receive explicit negative tests.

The initial scope is supplied-snapshot auditing. Live exporters, SQL semantic analysis, general migration planning, production load, HA/PITR, PKI/permission verification and managed-service adapters should be qualified separately when requested. Maintain mirrored skills and source/admission records when changing a rule.
